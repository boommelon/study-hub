计算机八股文 ​

一个月，把「上过课但忘了」的操作系统、网络、数据结构、数据库重新挂回一张网；再加上 AI 应用岗常问的 Python 与工程（GIL、生成器、装饰器、异步）。

怎么学 ​

  1. 读一篇：按侧栏顺序，每篇约 60 分钟。重点看「为什么这么设计」——八股的差距不在第一层（是什么），在第二层（为什么这样设计）和第三层（不这样会怎么坏）。
  2. 勾验收：文末的验收清单逐条勾掉。勾的标准是「不看资料能说出来」，不是「看过了」。
  3. 练本篇：文章顶部点「练本篇」，把这篇的自测题和面试题过一遍。
  4. 每天复习：首页「今日待复习」点进去，按间隔复习的节奏回顾旧卡。

三套类比（全库统一） ​

同一个词在全库永远指同一件事，这是这套资料能「连起来」的前提：

  • 餐厅 → 操作系统：CPU 是灶台，进程是客人点的一桌菜，内存是操作台，磁盘是后厨仓库，调度是排号。
  • 快递 → 计算机网络：IP 是收件地址，TCP 是带签收的快递单，DNS 是查地址簿，HTTP 是包裹里装的东西。
  • 图书馆 → 数据库：表是书架，索引是索引柜，事务是借还书流程，锁是借出登记本，MVCC 是多版本副本。
