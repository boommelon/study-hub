第八章　预测 ​

预测的理论核心是条件期望与误差方差。本章推导 ARMA 的预测公式与区间宽度，并解释为什么含单位根的模型区间会按根号 h 扩张。

8.1 最小均方误差预测 ​

在平方损失下，最优预测是条件期望：

ŷ_{T+h} = E(y_{T+h} | F_T)

其中 F_T 是到 T 期为止的全部信息。这就是"最小均方误差预测"（MMSE）。

严格说，条件期望在所有预测函数中最小化 MSE；若限定为线性函数，得到的是线性投影，两者只在联合正态下相同。ARMA 框架下的预测公式给出的正是线性投影。

预测误差：e_{T+h} = y_{T+h} − ŷ_{T+h}，其条件均值为零（无偏）。

8.2 AR(p) 的递推预测 ​

一步：ŷ_{T+1} = c + φ₁y_T + φ₂y_{T−1} + … + φ_py_{T−p+1}
二步：ŷ_{T+2} = c + φ₁ŷ_{T+1} + φ₂y_T + … + φ_py_

关键点是：多步预测时，未知的未来值用其预测值代入。随着 h 增大，越来越多的真实值被预测值替代，误差逐层累积。

当 h → ∞ 时，ŷ_{T+h} → μ = c/(1 − Σφᵢ)，即收敛到无条件均值。

8.3 MA(q) 的预测 ​

MA(q) 的记忆只有 q 期，因此：

当 h ≤ q：ŷ_{T+h} = μ + Σⱼ₌ₕ^q θⱼ ε_{T+h−j}
当 h > q：ŷ_{T+h} = μ

也就是说，超过 q 步之后，MA 的预测就是均值。这是 MA 模型"短记忆"的直接体现。

8.4 ARMA 的预测与误差方差 ​

用 MA(∞) 表示最方便：

y_{T+h} = μ + Σⱼ₌₀^∞ ψⱼ ε_

其中 j < h 的项含未来冲击（不可知，期望为零），j ≥ h 的项含已知的历史冲击。因此

ŷ_{T+h} = μ + Σⱼ₌ₕ^∞ ψⱼ ε_{T+h−j}

预测误差为

e_h = Σⱼ₌₀^{h−1} ψⱼ ε_{T+h−j}

由于 ε 相互独立、方差 σ²，误差方差为

Var(e_h) = σ² Σⱼ₌₀^{h−1} ψⱼ²

这个公式是全部预测区间理论的基石。三个直接推论：

  1. h 增大时求和项增多，方差单调不减；
  2. 当 h → ∞，方差收敛到 σ² Σⱼ₌₀^∞ ψⱼ²（无条件方差），前提是 ψⱼ 平方可和（平稳）；
  3. 若模型含单位根，ψⱼ 不衰减，方差随 h 无界增长。

8.5 预测区间 ​

在正态假设下，h 步预测的 95% 区间为

ŷ_{T+h} ± 1.96 · σ · √(Σⱼ₌₀^{h−1} ψⱼ²)

★ 区间宽度随 h 如何增长？ 取决于 ψⱼ 的衰减速度：

  • 平稳 ARMA：ψⱼ 指数衰减，Σψⱼ² 很快收敛 → 区间宽度很快趋于一个上界。
  • ARIMA(0,1,1)：ψ₀ = 1，ψⱼ = 1 + θ（j ≥ 1），不衰减 → Σψⱼ² = 1 + (h−1)(1+θ)²，与 h 成正比 → 区间宽度按 √h 增长。

这解释了为什么随机游走类模型的长期预测区间会张得非常大——这是模型性质的必然结果，不是估计不准。

★ 实际区间通常偏窄，原因有三：

  1. 忽略参数不确定性。公式把 φ、θ、σ² 当作已知，实际它们是估计出来的，会带来额外方差。
  2. 假设模型正确。结构变化、遗漏变量都会让真实误差大于公式值。
  3. 忽略厚尾与异方差。正态分位数在厚尾分布下偏小。

实践中可以用 bootstrap（重抽样残差、重新估计、重新预测）得到更接近真实的区间。

8.6 长期预测的收敛行为 ​

模型h → ∞ 时预测值区间宽度
平稳 ARMA（无常数）收敛到 0收敛到常数
平稳 ARMA（含常数）收敛到 μ = c/(1−Σφ)收敛到常数
ARIMA(p,1,q) 无漂移收敛到一条水平线（最后观测值附近）按 √h 增长
ARIMA(p,1,q) 含漂移收敛到一条斜率为 c 的直线按 √h 增长
趋势平稳（退势后建模）收敛到趋势线收敛到常数

★ 含漂移 ARIMA 的长期预测是一条直线，这是很多人看到"预测图后半段变成直线"的原因。这条直线的斜率完全由漂移项决定，所以漂移项是否可信，直接决定长期预测是否可信。若漂移不显著而仍被保留，长期预测就会带有一个方向明确但统计上无依据的趋势。

8.7 预测失效的三个来源 ​

  1. 模型错误：真实机制改变（结构突变），模型仍在用旧参数。
  2. 参数不确定性：参数估计误差在长预测期被放大。
  3. 不可预测的冲击：新信息本身不可预知，这是预测误差的下界，无法消除。

★ 三者中，第一类最致命也最常被忽视。任何模型的预测能力都以"生成机制不变"为前提，这个前提在长样本上几乎总是不成立。

8.8 组合预测 ​

把多个模型的预测加权平均：

ŷ_combo = Σᵢ wᵢ ŷᵢ

理论与实证都表明，简单平均（等权）往往优于估计最优权重。原因是权重估计本身有误差，在样本短时误差可能大于收益。

组合预测有效的前提是各模型的误差不完全相关。如果两个模型结构相似、误差高度相关，组合的收益很小。

8.9 两种预测协议的对比 ​

维度滚动一步固定原点多步
参数每个原点重新估计只在起点估计一次
信息集每期更新固定
预测步长恒为 11 到 h
误差结构只有一步误差误差随 h 累积
模拟的现实场景持续监控、每月更新一次性规划、中途不调整
典型用途评估模型的"更新能力"评估模型的"外推能力"

★ 一个常见的误判：看到滚动一步的 RMSE 很小，就认为模型"预测很准"。但滚动一步只预测下一个月，而实际业务往往需要预测一整年。两种协议的结论可能完全相反——滚动一步略优、固定原点明显劣于基准，是完全可能的，且这个组合本身很有信息量。

要点 ​

  1. 最优预测是条件期望；预测误差均值为零，方差为 σ²Σψⱼ²。
  2. AR 多步预测用预测值递归代入；MA 超过 q 步即回到均值。
  3. 平稳模型的区间宽度收敛到常数；含单位根的按 √h 增长。
  4. 含漂移 ARIMA 的长期预测是一条直线，斜率由漂移项决定。
  5. 组合预测的等权平均常优于估计权重，前提是误差不完全相关。
  6. 滚动一步与固定原点测的是两种能力，结论可以相反。

自测 3 问 ​

Q1：最优预测是什么？h 步预测误差的方差怎么算？

点开看答案

均方误差意义下的最优预测是条件期望。预测误差均值为零，方差为 σ²Σψⱼ²（j 从 0 到 h−1，ψⱼ 是 Green 函数权重）。

Q2：平稳模型和含单位根模型的预测区间，随预测步长怎么变化？

点开看答案
  • 平稳模型：区间宽度随 h 增大，最后收敛到一个常数；
  • 含单位根：区间宽度按 √h 增长，不收敛。

含漂移的 ARIMA，长期点预测是一条直线，斜率由漂移项决定。

Q3：AR 和 MA 的多步预测有什么不同？

点开看答案
  • AR：多步预测用前面的预测值递归代入；
  • MA(q)：超过 q 步后，预测回到均值（再往后已经没有可用的冲击信息）。
