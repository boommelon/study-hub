第二章　平稳性检验 ​

平稳性是 ARMA 建模的前提，但判断它从来不是单一检验能完成的。本章讲清 ADF 的三种设定、KPSS 的反向原假设，以及两者冲突时该怎么下结论。

2.1 图形判断：永远先看图 ​

在跑任何检验之前，先看两张图：

时序图：看均值是否漂移、方差是否变化、有无突变点、有无明显的周期。均值缓慢漂移或方差明显扩张，基本可以判定非平稳。

ACF 图：平稳序列的 ACF 快速衰减（指数或振荡式），通常在几个滞后内落入置信带；非平稳序列的 ACF 衰减极慢，长时间贴近 1。这是最可靠的图形判据之一。

图形不能替代检验，但能决定检验的设定——这一点在 2.3 节会看到有多重要。

打个比方：看图形就像医生进门先看病人的脸色和走路姿势。它不能代替化验单，但决定了该开哪几项检查——脸色发黄就查肝，不会一上来全套都做。跳过这一步直接跑检验，等于不看病人先开一叠化验单，然后对着一堆数字猜。

2.2 单位根与 DF 检验 ​

考虑一阶自回归

yₜ = φyₜ₋₁ + εₜ

当 |φ| < 1 时平稳；当 φ = 1 时为单位根过程（随机游走），非平稳。

检验问题是

H₀: φ = 1　　vs　　H₁: |φ| < 1

两边减去 yₜ₋₁，改写为

Δyₜ = γyₜ₋₁ + εₜ，　其中 γ = φ − 1

于是检验变为

H₀: γ = 0　　vs　　H₁: γ < 0

这是单侧检验。用普通 t 统计量 t = γ̂ / SE(γ̂) 判断，但这个统计量在原假设下不服从 t 分布，也不服从标准正态分布，而服从 Dickey-Fuller 分布——一个左偏的、临界值更负的分布。

★ 这一点极其重要：如果按普通 t 检验的 −1.65 去判断，会大幅高估拒绝率。DF 分布的 5% 临界值大约是 −2.86（含常数设定），比正态的 −1.65 负得多。软件报的 p 值已经是按 DF 分布算的，不要自己拿 t 分布表去查。

打个比方：这是换了一把尺子，不是同一个标准的微调。普通 t 统计量的分布在单位根问题下走了形——左偏、尾巴厚，所以临界值整体往左挪了一大截。你拿 −1.65 去卡，等于用"儿童身高标准"判断成年人，标准本身就错了，判出来的人自然一大片。

为什么会走形？因为原假设 φ = 1 时，序列的方差是 tσ² 在涨，统计量的抽样分布不再收敛到正态，而是收敛到一个由布朗运动决定的分布。分布变了，临界值当然要跟着变。

2.3 ADF 的三种设定 ​

实际数据往往有常数项和趋势，于是有三个设定：

设定一：无常数、无趋势

Δyₜ = γyₜ₋₁ + Σᵢ₌₁ᵖ δᵢΔyₜ₋ᵢ + εₜ

适用于均值为零的序列（如已差分的序列、收益率）。

设定二：含常数、无趋势

Δyₜ = c + γyₜ₋₁ + Σᵢ₌₁ᵖ δᵢΔyₜ₋ᵢ + εₜ

适用于均值非零但无趋势的序列。

设定三：含常数、含趋势

Δyₜ = c + βt + γyₜ₋₁ + Σᵢ₌₁ᵖ δᵢΔyₜ₋ᵢ + εₜ

适用于有明显确定性趋势的序列。

如何选择？ 常用的做法有两种：

  1. 从一般到特殊：先跑设定三，若趋势项 β 不显著（|t| < 1.96），去掉趋势跑设定二；若常数项也不显著且理论均值为零，再跑设定一。
  2. 看图形：时序图有明显上升/下降趋势 → 设定三；围绕非零水平波动 → 设定二；围绕零波动 → 设定一。

★ 设定选错的代价非常大，而且不对称。

  • 真实有趋势却用设定二（漏掉趋势项）：趋势会被 γ 项吸收，导致过度拒绝单位根（把非平稳判成平稳）。
  • 真实无趋势却用设定三（多放趋势项）：趋势项会吸收一部分均值回复的力量，导致功效大幅下降（把平稳判成非平稳）。

第二种情况更常见也更危险：含趋势设定的 ADF 检验功效很低。这就是为什么同一份数据在含趋势和仅含截距两种设定下可能给出完全相反的结论——一个说"不拒绝单位根"，一个说"拒绝单位根"。

打个比方：想象你要判断一个人有没有在长高，但量身高时脚下可能垫了砖。

  • 真实在长高（有趋势），却没把"长高"算进去：系统会把持续上涨误读成"偏离后被拉回"，于是判他"稳定"——这就是过度拒绝，把非平稳说成平稳。
  • 真实没长高（无趋势），却硬加一个趋势项：这个多出来的项会吃掉一部分本来存在的"往回走"的力量，让你看不出他其实在回落——功效骤降，把平稳说成非平稳。

第二种更危险，因为它像给没有楼梯的房子装扶手：不但没用，还把自己绊住。而且它不会报错，只会安静地给你一个"不拒绝单位根"的结论，让你白白多差一次分。

★ 遇到这种冲突怎么办？ 三条原则：

  1. 不要只报一个设定。 至少报告两种设定，并说明结论对设定敏感。
  2. 引入 KPSS 作为交叉验证（见 2.6）。KPSS 的原假设相反，能提供独立方向的证据。
  3. 以图形和差分后的表现为最终依据。 如果 ACF 衰减极慢、差分后 KPSS 通过、差分序列无明显过度差分信号，则 d = 1 是合理选择。

2.4 ADF 的"增广"与滞后阶数选择 ​

ADF 中的"增广"（Augmented）指的是加入 ΣδᵢΔyₜ₋ᵢ 这些差分滞后项，目的是消除残差的自相关，使检验统计量回到正确的分布。

打个比方：这是在测音量之前先贴吸音棉。房间里有余音（残差自相关），你测到的"这一声"里混着上一句的回声，读数就虚高、也不准。ADF 加滞后项，就是把回声吸掉，只留下干净的那一声。吸音棉贴少了（p 太小）回声还在，贴多了（p 太大）把原本的声音也吸掉了——所以要选 p。

滞后阶数 p 的选择有三条路：

  1. 信息准则：AIC 或 BIC 选 p。BIC 偏向更小的 p。
  2. 从大到小 t 检验：从最大滞后开始，逐个删去不显著的。
  3. 经验规则：p = ⌊12(T/100)^(1/4)⌋，月度数据常用 12。

★ 滞后阶数的双向影响：p 太小，残差仍有自相关，检验水平被扭曲（过度拒绝）；p 太大，损失自由度，功效下降。这是一个偏保守还是偏激进的选择，需要报告出来。

2.5 PP 检验 ​

Phillips-Perron 检验的思路不同：它不加入滞后差分项，而是用非参数方法修正检验统计量，以处理残差的自相关和异方差。

优点是无需选择滞后阶数（实际上只需选一个截断参数），缺点是小样本下表现不如 ADF 稳定。两者通常一起报告，结论一致时更有说服力。

打个比方：PP 和 ADF 的关系，像物理降噪和软件降噪。ADF 是贴吸音棉——在房间里把回声物理吸掉，代价是损失自由度（房间占了一块）；PP 是录音后用算法把回声扣掉——不动现场，但要依赖算法假设，样本短的时候扣不干净。两条路目的一样，副作用不同，所以常一起报，两个都说没事才更放心。

2.6 KPSS 检验 ​

KPSS 的原假设与 ADF 相反：

H₀: 序列是平稳的（水平平稳或趋势平稳）　　vs　　H₁: 存在单位根

打个比方：ADF 和 KPSS 是两种举证责任分配方式。

  • ADF 像"有罪推定"：先假定"你有单位根"（你有罪），你得像检察官一样拿出足够强的证据，才能推翻这个假定。
  • KPSS 像"无罪推定"：先假定"你平稳"（你无罪），同样得找证据才能推翻。

两个检验同时做，等于控辩双方各查一遍。如果两边都推翻不了，说明谁也没拿到硬证据——这正是下面那张表里最尴尬的"不拒绝 + 不拒绝"格。

它的构造思路是把序列分解为"确定性趋势 + 随机游走 + 平稳误差"，然后检验随机游走的方差是否为零。检验统计量基于累积残差：

LM = (1/n²) Σₜ₌₁ⁿ Sₜ² / σ̂²，　其中 Sₜ = Σᵢ₌₁ᵗ êᵢ

对应两种设定：检验"水平平稳"（只扣常数）与检验"趋势平稳"（扣常数和趋势）。

★ 为什么 ADF 与 KPSS 要一起用？ 因为两者的原假设互逆，构成一个二维的证据空间：

ADFKPSS解读
不拒绝不拒绝证据不足。可能样本太短，或序列接近单位根（φ 接近 1 但小于 1）
拒绝拒绝两个模型都不合适。常见于结构突变或非线性
不拒绝拒绝一致指向单位根，应差分
拒绝不拒绝一致指向平稳，不需要差分

关键的认识是：ADF 不拒绝 ≠ 证明有单位根，只说明"证据不足以推翻单位根"；KPSS 不拒绝 ≠ 证明平稳，同样只是证据不足。把"不拒绝"当成"接受"，是初学者最常见的逻辑错误。

打个比方：这就是**"证据不足，无罪释放"不等于"证明他无罪"**。法庭放人，是因为起诉方没能证明有罪，不是因为辩方证明了清白——这两件事天差地别。

所以"ADF 不拒绝单位根"的正确读法是"没有足够证据说它不是单位根"，而不是"它是单位根"。真正下结论要靠多条证据合起来：图形形态、两种设定的 ADF、KPSS 的方向、差分后的表现，四条对上了才敢拍板。

2.7 差分阶数 d 的确定流程 ​

综合以上，可以给出一个可操作的流程：

第一步：看图。 时序图判断有无趋势、有无方差变化；ACF 判断衰减速度。

第二步：对原序列做检验。 ADF（至少两种设定）+ KPSS（水平和趋势两种设定）+ 必要时 PP。

第三步：若一致指向非平稳，做一阶差分，重复第二步。

第四步：检查是否过度差分。 差分后 ACF 在滞后 1 是否出现约 −0.5 的负值？差分后方差是否反而变大？若是，说明多差了。

第五步：通常 d 不超过 2。 经济与金融数据绝大多数是 d = 0 或 1；d = 2 已属罕见，出现时应先怀疑结构突变或数据问题。

第六步：报告敏感性。 明确写出"结论对确定项设定敏感"以及最终依据，而不是宣称"所有检验一致"。

要点 ​

  1. DF/ADF 是单侧检验，统计量服从 DF 分布，不能用 t 分布临界值。
  2. ADF 三种设定对应不同确定性成分，设定错误会导致过度拒绝或功效骤降。
  3. KPSS 原假设与 ADF 相反，两者组合才能形成完整证据。
  4. "不拒绝"不等于"接受"，这是最常犯的逻辑错误。
  5. 差分阶数要靠图形 + 双检验 + 过度差分检查共同确定，并报告敏感性。

自测 3 问 ​

Q1：ADF 和 KPSS 的原假设分别是什么？为什么要一起用？

点开看答案
  • ADF：H₀ = 有单位根；
  • KPSS：H₀ = 平稳（与 ADF 相反）。

两者原假设互逆，合起来构成二维证据：ADF 不拒绝 + KPSS 拒绝 → 一致指向单位根，应差分；ADF 拒绝 + KPSS 不拒绝 → 一致指向平稳；两个都不拒绝 → 证据不足；两个都拒绝 → 两个模型都不合适，常见于结构突变或非线性。

Q2：「ADF 不拒绝单位根」能不能说成「证明有单位根」？为什么？

点开看答案

不能。不拒绝只说明「证据不足以推翻单位根」，不等于接受它——就像「证据不足，无罪释放」不等于「证明无罪」。

下结论要靠多条证据合起来：图形形态、两种设定的 ADF、KPSS 的方向、差分后的表现。

Q3：DF/ADF 检验能不能用 t 分布的临界值？ADF 设定选错会怎样？

点开看答案

不能。DF/ADF 是单侧检验，统计量在原假设下服从 DF 分布，不是 t 分布。

ADF 有三种设定，对应不同的确定性成分；设定错了会导致过度拒绝或功效骤降，所以要报告多种设定的结果。
